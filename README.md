# Bank Account Management System (C++)

A console-based mini project built with C++ using OOP concepts.

## Features
- Create and close accounts (Savings / Current)
- Deposit, withdraw and fund transfer
- Account summary, transaction statement and all-accounts report

## OOP Concepts
- Classes & Objects: Customer, Transaction, Account, Bank
- Encapsulation: private data members with public getters/methods

## Build & Run
g++ -std=c++11 BankManagementSystem.cpp -o bank
./bank
